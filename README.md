📌 Project Overview | نبذة عن المشروع

English:
Smart Parking Prediction is a Machine Learning project that predicts parking occupancy using historical parking data.
The model analyzes factors such as time, capacity, occupancy, and previous parking status.
It classifies parking areas into Low, Medium, or High occupancy.
The project aims to help drivers make better parking decisions and reduce time spent searching for spaces.

العربي:
مشروع Smart Parking Prediction يستخدم تقنيات تعلم الآلة للتنبؤ بنسبة إشغال مواقف السيارات اعتمادًا على البيانات التاريخية.
يحلل النموذج عوامل مثل الوقت، سعة الموقف، ونسبة الإشغال السابقة.
ثم يصنف حالة الموقف إلى إشغال منخفض أو متوسط أو مرتفع.
ويهدف المشروع إلى مساعدة السائقين على اتخاذ قرارات أفضل وتقليل الوقت المستغرق في البحث عن أماكن لركن السيارات.
